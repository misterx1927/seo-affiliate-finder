## Воспроизводимость

```python
import csv, random
with open('results/run-7-complete.csv', encoding='utf-8-sig', newline='') as f:
    urls = sorted({row['url'] for row in csv.DictReader(f)})
for url in random.Random(20261125).sample(urls, 20):
    print(url)
```

Статусы ответа взяты из CSV; причины ошибок и содержимое страниц — из локальной SQLite `data/live.db`, таблицы `run_pages` для запуска 7 и текущего `page_cache`. Кэш и `pages` могут меняться между запусками, поэтому это не гарантированно точный исторический снимок. Страницы с ошибкой загрузки в знаменателе сохранены, их содержимое не предполагалось по имени домена.

## Что эта проверка не доказывает

- Нет ручного эталонного списка **всех** брендов для каждой страницы; полноту и точность извлечения брендов в процентах оценить нельзя. Найден один вероятный дубль.
- Среди шести принятых ответов контакты не указаны. Поиск адреса в извлечённом фрагменте не заменяет проверку страницы, её формы связи и актуальности контакта; полнота контактов не измерена.
- Отсутствие текста или отказ в доступе не означает, что сайт не подходит. Страница YouTube требует другого способа извлечения содержания; домены с HTTP 403/451 требуют отдельной обработки и не должны автоматически получать выдуманную разметку.
- Доля доступности 9/20 относится к этой выборке и текущему кэшу, не является точной долей для всех будущих запусков. Источники позиций в CSV могут быть восстановлены DataForSEO через Google Web, как отмечено в таблице результатов.
