# Демонстрация проекта: сценарий на 3–4 минуты

Записывать после проверки итогового прогона: цифры и стоимость ниже нужно взять из фактически проверенного результата. В конце просмотреть запись перед передачей. Не показывать `.env`, вкладки API Access, биллинг, пароли и скриншоты с учётными данными.

## Подготовка

1. Запустить приложение по README, закрыть лишние вкладки и уведомления. Открыть боковое меню, выбрать **Реальные результаты** и убедиться, что результаты отображаются. При отсутствии локальной базы показать таблицу из `results/` и отдельно назвать данные в режиме **Демо** вымышленными.
2. Подготовить проверенную таблицу итогового запуска, README и заметку с числами: количество ключей, полных десяток, доступных AI-разметок и требующих ручной проверки страниц. Подготовить подтверждённую стоимость и отдельно обозначить случаи, где у провайдера не удалось узнать точную сумму.
3. Например, в Windows 11 открыть «Ножницы» → **Запись** (или Win + Shift + R, если горячая клавиша доступна), выделить окно приложения и начать запись. Проверить микрофон, если выбранный способ его поддерживает. Остановить запись и сохранить файл; при необходимости использовать привычную программу записи экрана. Доступность записи звука зависит от версии Windows и настроек.

## Текст и действия

**0:00–0:25 — задача.** Открыть приложение. «Этот прототип помогает искать площадки для размещения казино-брендов. Он собирает органическую выдачу Google для Канады, английского языка и мобильных устройств по десяти ключам, а затем анализирует найденные страницы».

**0:25–1:15 — результаты.** Показать **Реальные результаты**, общие показатели и таблицу. «Здесь видны запрос, позиция, URL и домен, оценка релевантности, найденные бренды и доступный контакт. Можно искать по названию и фильтровать результаты». Показать фильтр и экспорт CSV/Excel для полных результатов. Если открываете **Демо**, прямо сказать: «Это вымышленные данные для демонстрации интерфейса».

**1:15–1:50 — качество и исключения.** Показать фильтр **Нужна проверка**. «Неполные выдачи сохранены отдельно. Если сайт не открылся или данные не удалось подтвердить, он требует ручной проверки». Показать пример записи и реальные поля, не утверждая, что все страницы проверены или все контакты существуют.

**1:50–2:25 — повторный запуск и история.** Показать README или итоговую выгрузку. «Позиции сохраняются по датам; повторный полный сбор за тот же день заменяет дневной срез, не создавая дублей. Сбор запускается отдельно от интерфейса, ежедневное расписание можно настроить снаружи». Не показывать историю как график или запуск из интерфейса: таких функций сейчас нет.

**2:25–3:00 — результаты, стоимость, ограничения.** Назвать только подтверждённые числа итогового запуска и стоимость с учётом оговорок. Если включалась проверка искажений выдачи, объяснить: «Часть позиций могла быть восстановлена из Google Web, что указано в данных; это не обязательно точная копия исходной мобильной страницы». Упомянуть блокировки сайтов и необходимость проверки качества брендов и контактов.

**3:00–3:20 — передача.** Показать репозиторий, README и приложенные результаты, когда они готовы. «В README — установка, запуск, стоимость, ограничения и дальнейшие улучшения». Не показывать репозиторий как опубликованный, пока ссылка не создана.

После записи проверить звук, читаемость, длительность до пяти минут и отсутствие секретов. Точный способ передачи видео выбрать согласно инструкции работодателя; загрузка и отправка выполняются отдельно.
