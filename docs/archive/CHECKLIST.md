## Проверка качества 20 страниц

Для каждого URL зафиксировать дату и запрос, фактический тип сайта, ответ программы, наличие ошибок, пропущенные или лишние бренды и контакты, а также причину несогласия. Для недоступных страниц отметить `needs_review`; не считать их ни верными, ни неверными без ручного осмотра. Разделить ошибки классификации, извлечения и загрузки. Измерить долю совпадений только по страницам, которые удалось оценить.

## Дальнейший запуск по расписанию

Windows Task Scheduler может запускать полную команду из папки проекта с тем же пользовательским аккаунтом, у которого есть доступ к локальному `.env` и базе. Расписание сейчас не создаётся: оно будет генерировать расходы, поэтому его можно настраивать только после успешного пилота, проверки лимитов и отдельного согласования. Учесть, что компьютер должен быть включён, а учётные данные не должны записываться в аргументы команды или журналы.
