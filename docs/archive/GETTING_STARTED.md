# Подготовка к живому запуску

Бесплатная демонстрация и инструкция по установке находятся в [README](README.md). Она работает на вымышленных данных без регистрации и оплаты.

Для реального запуска нужны подтверждённый аккаунт DataForSEO с доступом к Google Organic SERP API и аккаунт OpenAI с доступом к указанной модели и API-балансом. Создайте `.env` из `.env.example` и заполните его локально; секреты нельзя публиковать вместе с проектом. Баланс API OpenAI и подписка ChatGPT учитываются отдельно.

Команда `pilot.py --mode full` по умолчанию показывает параметры без запросов. Полная команда для платного запуска есть в README. До запуска проверьте актуальные тарифы и ограничения в кабинетах обоих сервисов. Резерв в программе помогает ограничить число запросов, но не является жёстким лимитом провайдеров. Автоматических повторов платных запросов нет.

Снимки уже проведённого запуска находятся в `results/`. Они показывают реальный, но частичный результат: по 8 из 10 поисковых запросов сервис вернул меньше 10 результатов. Сбор по расписанию необходимо настраивать отдельно после проверки стоимости и результатов.
